How the OAuth 2.1 Flow Works

1
Click Connect
AI client hits /mcp → 401 + WWW-Authenticate with resource_metadata URL
2
Discovery
Fetches /.well-known/oauth-protected-resource (RFC9728)
3
AS Metadata
Fetches AS metadata, confirms PKCE S256 support (RFC8414)
4
Login
You authenticate & approve on the consent page
5
Token
Client exchanges code + PKCE verifier for JWT access token
6
MCP Access
AI calls tools — all data scoped to YOUR user account

MethodPathPurpose
